Beatbox fuer RG35XX (MinUI)
===========================
Ablegen: SD-Karte -> Tools -> (Plattform-Ordner, dort wo auch Clock.pak liegt) -> Beatbox.pak
Starten: MinUI -> Tools -> Beatbox

Erster Start: Das Programm fragt nacheinander alle Tasten ab (einmalige Einrichtung).
Neu einlernen: SELECT + MENU gedrueckt halten/druecken, oder die Datei bbmap.cfg loeschen.

Steuerung (Raster)
  Steuerkreuz        Cursor bewegen
  A                  Step: aus -> an -> Akzent -> aus (spielt den Klang an)
  B + Steuerkreuz    HOCH/RUNTER: Lautstaerke der Spur, LINKS/RECHTS: Tonhoehe
  X                  Spur stumm / laut
  Y                  Zeile leeren
  L / R              Pattern A-D wechseln (waehrend des Spielens: am Taktende)
  START              Play / Stop
  SELECT + HOCH/RUNTER   Tempo (BPM)
  SELECT + LINKS/RECHTS  Swing
  SELECT + L / R     Kit wechseln (laedt den Beat des Kits ins aktuelle Pattern)
  SELECT + A         Beat des Kits neu laden
  SELECT + Y         ganzes Pattern leeren
  SELECT + START     Effekt-Seite (Filter, Delay, Hall, Drive, Crush)
  MENU               Speichern und Beenden

Effekt-Seite
  HOCH/RUNTER Parameter waehlen, LINKS/RECHTS Wert aendern, A Effekte an/aus,
  Y zuruecksetzen, SELECT+START zurueck.

Gespeichert wird in bbsave.dat (neben dem Programm), Tastenbelegung in bbmap.cfg.
Fehlersuche: beatbox.log im Pak-Ordner.
